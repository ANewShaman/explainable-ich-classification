## Preprocessed Dataset

The models use three-channel CT representations:

- R: W80/L40 — brain/soft-tissue window
- G: W200/L80 — subdural/blood-brain window
- B: W2000/L600 — bone window

Download the preprocessed dataset: https://www.kaggle.com/work/collections/19027592


The original RSNA dataset link: https://www.kaggle.com/competitions/rsna-intracranial-hemorrhage-detection/data

The PM-CT scans for domain-shift inference were procured by NMDID upon request to the institution.
